# Privacy Request

**Owner:** privacy operations. **Trigger:** verified access, correction,
export, deletion, restriction, objection, or consent-withdrawal request.

1. Record request type, jurisdiction, tenant, deadline, and identity-verification
   result using the minimum necessary data.
2. Reject unverifiable or cross-tenant access; escalate conflicts to privacy/legal.
3. Inventory governed data stores, exports, caches, backups, processors, legal
   holds, and source-system ownership.
4. Produce a redacted, scoped export or correction plan. Deletion is separately
   authorized, hold-aware, auditable, and never performed by local checkers.
5. Record processor/source referrals, exceptions, receipts, and requester
   communication without copying raw content into general logs.
6. A second reviewer validates scope and completion evidence before closure.

Consent withdrawal disables future optional processing; it does not override a
documented legal hold.
